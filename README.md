# ZZZ 와이프아웃 캡처

젠레스 존 제로에서 마지막 적을 쓰러뜨리면 나오는 **WIPEOUT** 연출을 장면마다 자동으로 캡처합니다.
도전 결과 화면의 "한 번 더" 왼쪽에 버튼이 생기고, 누르면 찍힌 장면을 보고 저장할 수 있습니다.

## 기능

- WIPEOUT 연출의 장면(2~4개)을 장면마다 자동 캡처합니다.
- 화면이 지지직거리거나 가로줄이 심한 순간은 피하고, 가장 깨끗한 순간을 고릅니다.
- 도전 결과 화면에 버튼을 띄웁니다. 캡처한 장면이 있을 때만 나타납니다.
- 게임 위에 확인 창을 띄웁니다. 게임 포커스를 빼앗지 않습니다.
- 사진을 누르면 크게 보고, 이전/다음으로 넘기고, 한 장씩 저장할 수 있습니다.
- 이미 저장한 사진은 저장 버튼에 초록 체크가 표시됩니다.
- 결과 화면을 나가면 확인 창이 자동으로 닫힙니다.

## 설치와 실행

1. [Releases](../../releases)에서 `ZZZ-Wipeout.zip`을 받습니다.
2. 압축을 풉니다. 계속 둘 폴더에 푸세요.
3. `ZZZ-Wipeout.exe`를 더블클릭합니다. 설정 창이 열립니다.
4. 설정 창을 닫아도 프로그램은 뒤에서 계속 동작합니다. 트레이 아이콘(작업 표시줄 오른쪽 아래)은 게임이 켜져 있을 때만 보입니다.

게임은 평소대로 실행하세요. 관리자 권한은 필요 없습니다.
따로 설치할 것은 없습니다. 필요한 .NET Framework 4.8은 Windows 10/11에 기본으로 들어 있습니다.

## 설정

다음 중 하나로 설정 창을 엽니다.
- 확인 창 오른쪽 위의 톱니바퀴 버튼을 누릅니다.
- 트레이 아이콘을 더블클릭합니다.
- `ZZZ-Wipeout.exe`를 다시 실행합니다. 게임이 꺼져 있을 때는 이 방법을 씁니다.

| 항목 | 설명 | 기본값 |
| --- | --- | --- |
| 저장 폴더 | 장면을 저장할 폴더 | 사진\젠존제 와이프아웃 |
| 자동 저장 | 캡처가 끝나면 모든 장면을 바로 저장 | 꺼짐 |
| 결과 화면 버튼 | 도전 결과 화면에 버튼 표시 | 켜짐 |
| 원본 화질 (PNG) | 켜면 무손실 PNG(장당 4~5MB), 끄면 고화질 JPG(장당 1MB 안팎) | 꺼짐 |
| 장면당 캡처 수 | 한 장면에서 깨끗한 순서로 남길 장수 (1~10장) | 3 |
| 녹화에 보이기 | 버튼과 확인 창이 녹화·스크린샷에 찍힘 | 켜짐 |
| Windows 로그인 시 자동 실행 | 로그인할 때 자동으로 켜짐. exe를 다른 폴더로 옮겨도 한 번 실행하면 새 위치로 바뀜 | 꺼짐 |

트레이 아이콘 우클릭 메뉴: 설정 / 최근 캡처 보기 / 저장 폴더 열기 / 종료

## 지원 환경

- Windows 10/11 64비트
- 16:9 화면 비율. 다른 비율에서는 결과 화면 버튼 위치가 어긋날 수 있습니다.
- 게임 언어: 한국어. 결과 화면을 "완료" 글자로 알아봅니다.

## 삭제

1. 설정 창에서 "Windows 로그인 시 자동 실행"을 끕니다.
2. 게임을 켠 상태에서 트레이 아이콘 우클릭 → 종료를 누릅니다.
3. 폴더를 삭제합니다.
4. 설정 파일까지 지우려면 `%APPDATA%\젠존제 와이프아웃` 폴더도 삭제합니다.

## 자주 묻는 질문

**Windows가 "PC 보호" 창을 띄웁니다.**
서명되지 않은 프로그램이라 나오는 창입니다. "추가 정보" → "실행"을 누르세요.
소스 코드는 이 저장소에 모두 공개되어 있습니다. 직접 빌드할 수도 있습니다(아래 "직접 빌드" 참고).

**저장이 안 됩니다.**
Windows 보안의 "제어된 폴더 액세스"가 사진 폴더 쓰기를 막을 수 있습니다.
막히면 `C:\Users\사용자이름\젠존제 와이프아웃`에 대신 저장합니다. 설정에서 저장 폴더를 바꿔도 됩니다.

**캡처가 안 됩니다.**
게임 창이 앞에 있어야 동작합니다. 연출 도중 다른 창으로 넘어가면 캡처하지 않습니다.

## 동작 방식

- 게임 창이 앞에 있을 때만 0.1초마다 화면 위쪽 한 줄을 봅니다.
- 화면이 노랗게 바뀌면 WIPEOUT 연출로 보고, 연출이 끝날 때까지 화면을 연속으로 찍습니다.
- 찍은 화면을 작게 줄여 장면을 나누고, 장면마다 흔들림·가로줄·지글거림이 가장 적은 순간을 남깁니다.
- 화면을 읽기만 합니다. 게임 메모리와 파일은 건드리지 않고, 키 입력도 보내지 않습니다.

## 주의

비공식 프로그램입니다. HoYoverse와 관계가 없습니다.
사용 책임은 사용자에게 있습니다. 화면만 읽지만, 게임 약관 위반이나 계정 제재 가능성이 0은 아닙니다.

## 직접 빌드

[.NET SDK](https://dotnet.microsoft.com/download)(8 이상)를 설치한 뒤 저장소 폴더에서 실행합니다.

```
dotnet build -c Release
```

결과 파일은 `bin\Release\net48\ZZZ-Wipeout.exe`입니다.
